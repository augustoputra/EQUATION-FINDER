EQUATION FINDER — STREAMLIT APP

Run locally:
1. Install Python 3.10+.
2. Open a terminal in this folder.
3. Install dependencies:
   pip install -r requirements.txt
4. Start the app:
   streamlit run app.py
5. Open the local URL shown in the terminal (usually http://localhost:8501).
6. Upload your Excel workbook and select inputs/target.

To make it accessible to others, deploy the app folder to Streamlit Community Cloud:
https://share.streamlit.io/
Include app.py and requirements.txt in the connected GitHub repository.
